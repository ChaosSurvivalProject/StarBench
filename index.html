ⓘ 温度告知与合规声明
  • 浏览器无法读取 SoC 结温 / thermal headroom / 频率 / 风扇，相关字段一律输出 unavailable；禁止用 FPS 下降反推「过热」或下结论。
  • 不锁频、不提频、不对抗温控；不请求任何设备权限、不读取传感器、不做长时间高负载折磨测试；提供随时「停止」与自动结束。
  • 本页为自写体素世界 + 自写噪声 + 自绘贴图的等效负载生成器，仿《我的世界》运算形态，非官方客户端，不宣称 1:1 还原，不预测 MC 真实帧率，不与 3DMark/安兔兔/原生客户端分数互换。
  • 纯本地运行：不上传任何逐帧数据、无账号、无排行榜。所有历史仅存于本机浏览器。
  • Minecraft / Java Edition / Bedrock Edition 名称仅作负载剖面描述；商标归 Mojang/Microsoft 所有，本项目与其无关联，不含任何官方美术资源或代码。
⚠ 检测到软件渲染（SwiftShader/llvmpipe）。结果受软件光栅化瓶颈主导，不具跨设备区分力，仅供本机观察。
